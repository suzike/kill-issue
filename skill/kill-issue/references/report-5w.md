# 5W 分析报告模板

> 使用说明：本模板是 **5W 分析报告** 的唯一结构。适用场景：责任归属有争议、需要把事实与责任方摆清楚、或需要快速对齐认知时。
> 5W 的 W 顺序按"事实 → 位置 → 条件 → 责任 → 原因"推进，最后落到 How（解决与验证）。
> 写作遵守 SKILL.md 第三节硬性规范：结论先行、图文并茂、结构化语言、禁信号名堆砌、信号名必配语义翻译。
> 用不到的小节写"不适用"，不要删掉导致结构不齐。

## 2. W1 What —— 发生了什么（现象事实）

| 维度 | 定位 |
|---|---|
| 功能/子系统 | （如：某控制回路 / 状态机 / 执行器控制） |

## 4. W3 When —— 什么条件下发生

- 工况：模式、温度、车速、档位、车型/功能配置（如 5S/6S）
- 时序：复现步骤 1. 2. 3.；频率（必现/偶发）
- 版本：软件/模型/标定版本与构建时间
- 变更背景：（是否新引入、最近改了什么）

| 需求 | （需求定义不清或矛盾） | 是/否/存疑 |
| 其他 | （外部联动、整车集成、供应商） | 是/否/存疑 |

**判定结论**：（主次责任层 + 一句话依据；每个"否"给排除理由，避免被质疑漏判）
